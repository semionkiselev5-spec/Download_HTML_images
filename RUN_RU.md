# Установка и запуск Download_HTML_images

Программа сохраняет выдачу Яндекс Картинок в HTML по каждому запросу из вашего JSON. Для локальной проверки ключи S3 не нужны. Для публикации по ссылкам потребуется хранилище с доступом на запись и публичное чтение.

## Скачать проект

На [странице репозитория](https://github.com/semionkiselev5-spec/Download_HTML_images) нажмите **Code → Download ZIP** и распакуйте архив. Или скачайте проект через Git:

```bash
git clone https://github.com/semionkiselev5-spec/Download_HTML_images.git
cd Download_HTML_images
```

Все дальнейшие команды выполняйте в папке проекта. В ней должны лежать `sbs_capture_single.py`, `requirements.txt`, `input.json` и `config.images.standard.json`.

## Установить Python и зависимости

Нужен Python 3.10 или новее. Если Python не установлен, скачайте установщик с [официальной страницы](https://www.python.org/downloads/). В Windows включите **Add Python to PATH**, если установщик предлагает этот пункт.

### macOS и Linux

Откройте Терминал в папке проекта:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### Windows

Откройте **cmd** в папке проекта:

```bat
py --version
py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
```

При следующем открытии терминала перейдите в папку проекта и снова активируйте `.venv`. Для macOS и Linux это `source .venv/bin/activate`, для Windows в cmd — `.venv\Scripts\activate.bat`.

## Подготовить свой JSON

Скопируйте `input.json` в `my_queries.json` и замените запросы на свои. Пример:

```json
[
  {"query": "горный пейзаж", "region_id": 213, "device": "ANDROID"},
  {"query": "современная архитектура", "region_id": 213, "device": "DESKTOP"}
]
```

У каждой записи должны быть три поля:

| Поле | Значение |
| --- | --- |
| `query` | Непустой текст запроса |
| `region_id` | Целый идентификатор региона поиска от 0 |
| `device` | `DESKTOP`, `ANDROID` или `IPHONE` |

Поддерживаются также один JSON-объект и JSONL — по одному объекту в строке. Сохраните файл в UTF-8. Порядок запросов соответствует `input_index` в отчёте.

## Проверить без S3

Сначала выполните запуск с примером:

```bash
python sbs_capture_single.py --input input.json --config config.images.standard.json --output runs-local --local-only
```

Для своего списка замените путь после `--input`:

```bash
python sbs_capture_single.py --input "my_queries.json" --config config.images.standard.json --output runs-local --local-only
```

Можно указать полный путь к JSON в другой папке. Пути с пробелами заключайте в кавычки. Флаг `--local-only` отключает загрузку в S3: без него программа пытается публиковать страницы.

После запуска откройте подпапку с идентификатором запуска внутри `runs-local`. В ней будут HTML каждого запроса и отчёт `results.json`. Поле `html_path` указывает путь к странице на вашем ноутбуке. Откройте её в браузере; для исходных изображений, стилей и просмотрщика нужен интернет. В локальном режиме публичных ссылок нет.

## Публикация в S3

В `config.images.standard.json` заполните `s3.endpoint`, `s3.region`, `s3.bucket` и `s3.prefix` для своего хранилища. Текущие значения соответствуют исходной настройке автора. Параметр `acl` должен подходить вашему провайдеру. Программа проверяет публичное чтение загруженного HTML; бакет должен разрешать такой просмотр. При другом публичном домене можно добавить `s3.public_base_url`.

Ключи передаются через переменные окружения `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY` либо стандартный AWS-профиль. Скрипт **не читает `.env` автоматически**.

### Ввод ключей без сохранения в файл

С активированной `.venv` откройте Python:

```bash
python
```

В приглашение `>>>` вставьте эту строку и нажмите Enter:

```python
exec('import os, sys, getpass\nos.environ["AWS_ACCESS_KEY_ID"] = getpass.getpass("Access Key ID: ")\nos.environ["AWS_SECRET_ACCESS_KEY"] = getpass.getpass("Secret Access Key: ")\nos.execv(sys.executable, [sys.executable, "sbs_capture_single.py", "--input", "my_queries.json", "--config", "config.images.standard.json", "--output", "runs-s3"])')
```

Перед вставкой замените `my_queries.json` на имя или путь к своему файлу. Введите ключи по запросу: символы будут скрыты. Этот способ работает в терминале на macOS, Linux и Windows и не сохраняет ключи в проекте.

### Если ключи уже настроены

```bash
python sbs_capture_single.py --input "my_queries.json" --config config.images.standard.json --output runs-s3
```

В macOS или Linux можно вручную подключить файл `.env`: скопируйте `.env.example` в `.env`, впишите ключи и выполните:

```bash
set -a
source ./.env
set +a
python sbs_capture_single.py --input "my_queries.json" --config config.images.standard.json --output runs-s3
```

Файл `.env` исключён из Git. Подключение относится к текущему терминалу.

## Где искать результаты и ссылки

Каждый запуск создаёт новую подпапку внутри указанного `--output`:

| Файл или поле | Содержимое |
| --- | --- |
| `*.html` | Локальные HTML-страницы |
| `*.json` рядом с HTML | Сведения о запросе, карточках и выгрузке |
| `results.json` | Результаты всех обработанных запросов |
| `urls.txt` | Успешно опубликованные ссылки S3, по одной на строку |
| `s3_url` | Публичная ссылка в записи результата |
| `html_path` | Путь к локальному HTML |

При успешной публикации ссылка также выводится в терминал отдельной строкой `HTML: https://...`. Статус `"ok"` означает успех в выбранном режиме. При `"error"` причина указана в поле `error`; остальные запросы продолжают обрабатываться. Наличие `html_path` без `s3_url` не означает, что публикация прошла.

## Настройки выдачи и блюра

По умолчанию для `DESKTOP` цель — не менее 90 картинок, до пяти страниц; последняя страница сохраняется целиком. Если выдача закончилась раньше, фактическое количество отражается в метаданных. Для `ANDROID` и `IPHONE` сохраняется одна страница.

Программный блюр отключается у всех изображений в каждой выгрузке, включая просмотрщик. `remove_blur` принудительно устанавливается в `true`, даже если внешний конфиг содержит `false`. Это правило действует и для обработки сохранённого HTML через `--html`.

Картинки сохраняются как в `yandex old`: исходные URL изображений, стилей и скриптов остаются в HTML. Их загружает браузер при просмотре; скрипт не скачивает все оригиналы картинок отдельно.

Хост, экспериментальные параметры, лимиты страниц и S3 задаются в конфиге. При запуске без `--config` используются встроенные настройки `DEFAULT_CONFIG` исходного скрипта.

## Частые вопросы

**В терминале нет публичной HTML-ссылки.** Проверьте режим запуска. `--local-only` сохраняет файлы на ноутбуке. При публикации S3 смотрите поле `error`, если статус запроса — `"error"`.

**Ошибка доступа к S3.** Проверьте ключи, бакет и права на запись и публичное чтение. Настройки бакета задаются в JSON-конфиге.

**Файл JSON не найден.** Проверьте путь после `--input`. Для файла вне папки проекта укажите полный путь в кавычках.

**Ошибка JSON.** Проверьте двойные кавычки, запятые и кодировку UTF-8.

**`No module named ...`.** Активируйте `.venv` и повторите `python -m pip install -r requirements.txt`.

Коды завершения: `0` — все запросы успешны, `1` — ошибки отдельных запросов, `2` — ошибка настройки или запуска.
